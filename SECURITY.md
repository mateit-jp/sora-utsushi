# セキュリティの問題の報告

このリポジトリの **Security** タブの **Report a vulnerability**（非公開の報告）からお知らせください。
公開の Issue には書かないでください。

- 対象: このリポジトリのコードと、公開中のサイト
- 対象外: 止まっているサービスそのもの（その事業者へ連絡してください）
- 報奨金はありません。返事は数日以内を目安にします。

## Reporting a vulnerability

Please use **Report a vulnerability** in the **Security** tab (private vulnerability reporting).
Do not open a public issue. This is an unofficial site and is not affiliated with the affected service.
